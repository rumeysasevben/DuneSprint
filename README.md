# 🏜️ Dune Sprint

An endless runner game set in a vast desert landscape, built with **Unity 6**. Run, jump, and slide through procedurally generated desert terrain while collecting stars and dodging obstacles.

## 🎮 Gameplay

https://github.com/user-attachments/assets/YOUR_VIDEO_LINK_HERE

- **Run** through an endless desert environment
- **Jump** over obstacles (Space / W / ↑)
- **Slide** under barriers (S / ↓)
- **Collect stars** to boost your score
- **Survive** as long as possible — the speed increases over time!

## ✨ Features

- Procedurally generated desert segments for endless replayability
- Dynamic difficulty scaling — speed increases as you progress
- Star collection system with persistent high score
- Smooth camera follow with screen shake on impact
- Full sound system (background music, jump, slide, coin, impact SFX)
- Main Menu with animated title and dust particle effects
- Pause system (ESC or in-game button)
- Game Over screen with distance, total stars, and best score display

## 🛠️ Built With

- **Engine:** Unity 6 (6000.2.3f1)
- **Language:** C#
- **Render Pipeline:** Universal Render Pipeline (URP)
- **3D Assets:** Low Poly Desert Pack, Mixamo characters & animations
- **UI:** TextMeshPro

## 🎮 Controls

| Action | Key |
|--------|-----|
| Move Left | A / ← |
| Move Right | D / → |
| Jump | Space / W / ↑ |
| Slide | S / ↓ |
| Pause | ESC |

## 📁 Project Structure

```
Assets/
├── Animations(mixamo)/   # Character animations (Run, Jump, Slide)
├── Characters/           # Player character model & sounds
├── LowPoly Environment Pack/  # Desert terrain & obstacle assets
├── Scenes/               # MainMenu & SampleScene (gameplay)
└── Scripts/              # C# game scripts
```

## 🚀 How to Play

1. Clone the repository
2. Open in Unity 6 (6000.2.3f1 or later)
3. Open `Scenes/MainMenu`
4. Press Play
